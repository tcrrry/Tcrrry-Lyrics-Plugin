# 安装与测试

1. 使用带作者 **AM++ SDK v1插件管理器**的宿主，确认 Apple Music 是 `7.0.0-beta / 1606`。
2. 在插件管理器导入 `Tcrrry-Lyrics-Plugin-1.0.3.zip`。旧的 `Tcrrry Lyrics Compatibility 0.1.0` 只是兼容原型，若已装请停用它，避免重复处理。
3. 启用本插件并重启 Apple Music。若管理器提示同一目标被多个功能修改，这是与内置歌词功能的重叠提示；不支持的版本、独占冲突或加载错误须先处理，不能跳过。
4. 从管理器打开本插件自己的设置，或长按播放页的歌词来源行进入 Tcrrry 设置。配置质量/逐字偏好、辉光和注音。
5. 需要离线机翻时另装 `Tcrrry-Lyrics-Offline-1.0.3.apk`，首次打开完成连接授权；下载中文和原语言模型，再执行验证。模型是用户主动下载，不会随插件自动下载。只用平台译文/API翻译/注音可不安装。

不要把插件 ZIP交给 Android安装器，不要安装 `engine-release-unsigned.apk`。没有插件管理器的普通 v1.5不能导入；是否需要 root取决于宿主由 LSPosed还是内置补丁装载 AM++，插件 ZIP本身不是 root模块。

## 原作者验收建议

- 原生逐字+QQ／网易云译文：原文时间不变，来源说明显示真实辅助来源；错版本或错时间不可混入。
- 日语/韩语突出发音：依据真实原文单元逐字扫亮；无可靠对齐的句子只逐行回退；翻译与上方辅助发音不随主行高亮。
- 快速反复切源/恢复最佳/恢复自动：不递次丢弃最佳候选，超时/限频保留好结果；旧歌曲后台回包不覆盖新歌。
- 尾奏第一次回拖、单曲循环、暂停回拖：恢复聚焦，不需重复拖动或退出重进；QQ/网易云/原生均测。
- 辉光500%、尾音位置、短单元平滑、长行/大字体设置气泡。
- 开始播放后停用插件：重启后没有注入行/后台任务；更新保留插件设置，删除后只删除插件目录。
- 原生设置首次进入、切歌封面：这些宿主级改动不由本歌词插件接管，需在作者宿主上回归。

无需卸载现有含下载歌曲的 v1.5来验收 ZIP；先把导入包交给具备插件宿主的原作者测试即可。

本次覆盖更新：逐字优先查完可用逐字来源后，若均无逐字，按 Apple Music 原生 → AM++ 适配库 → QQ／网易云等第三方的质量顺序选择逐行；手动选源仍优先。译文保留原生／AM++ 当前歌词自带的可靠译文，再补 QQ／网易云，最后机翻。双击来源仅寻找当前来源其他匹配，单击换来源、长按打开设置。
