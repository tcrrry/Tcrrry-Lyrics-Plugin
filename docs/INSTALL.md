# 安装与更新

这是 Tcrrry 维护的 AM++ 第三方插件。当前正式版本 **1.0.3** 已由用户在 **AM++ 105 嵌入版**完成实机验收，暂未发现问题。其他及后续宿主版本未在本次验收中验证。

请从[正式版下载页](https://github.com/tcrrry/Tcrrry-Lyrics-Plugin/releases/tag/plugin-v1.0.3)选择附件。主插件 ZIP、伴随 APK、源码 ZIP 的用途不同，只有主插件 ZIP 应导入插件管理器。

**需要离线机翻：同时下载主插件 `Tcrrry-Lyrics-Plugin-1.0.3.zip` 和伴随服务 `Tcrrry-Lyrics-Offline-1.0.3.apk`，分别导入插件、安装 APK，再下载语言模型。仅安装插件不能使用离线机翻。** 已有旧版伴随 APK 可继续使用；平台已有译文、API 翻译和词典注音不要求安装伴随 APK。

1. 使用已经测试的 **AM++ 105 嵌入版**及其 **SDK v1插件管理器**，确认 Android 12及以上、Apple Music `7.0.0-beta / 1606`。
2. 在插件管理器导入 `Tcrrry-Lyrics-Plugin-1.0.3.zip`。旧的 `Tcrrry Lyrics Compatibility 0.1.0` 只是兼容原型，若已装请停用它，避免重复处理。
3. 启用本插件并重启 Apple Music。若管理器提示同一目标被多个功能修改，这是与内置歌词功能的重叠提示；不支持的版本、独占冲突或加载错误须先处理，不能跳过。
4. 从管理器打开本插件自己的设置，或长按播放页的歌词来源行进入 Tcrrry 设置。配置质量/逐字偏好、辉光和注音。
5. 需要离线机翻时另装 `Tcrrry-Lyrics-Offline-1.0.3.apk`，首次打开完成连接授权；下载中文和原语言模型，再执行验证。模型是用户主动下载，不会随插件自动下载。只用平台译文/API翻译/注音可不安装。

不要把插件 ZIP交给 Android安装器，不要安装 `engine-release-unsigned.apk`。没有插件管理器的普通 v1.5不能导入；是否需要 root取决于宿主由 LSPosed还是内置补丁装载 AM++，插件 ZIP本身不是 root模块。

## 使用时可核查的行为

- 原生逐字+QQ／网易云译文：原文时间不变，来源说明显示真实辅助来源；错版本或错时间不可混入。
- 日语/韩语突出发音：依据真实原文单元逐字扫亮；无可靠对齐的句子只逐行回退；翻译与上方辅助发音不随主行高亮。
- 快速反复切源/恢复最佳/恢复自动：不递次丢弃最佳候选，超时/限频保留好结果；旧歌曲后台回包不覆盖新歌。
- 尾奏第一次回拖、单曲循环、暂停回拖：恢复聚焦，不需重复拖动或退出重进；QQ/网易云/原生均测。
- 辉光500%、尾音位置、短单元平滑、长行/大字体设置气泡。
- 开始播放后停用插件：重启后没有注入行/后台任务；更新保留插件设置，删除后只删除插件目录。
- 原生设置首次进入、切歌封面：这些宿主级改动不由本歌词插件接管，需在作者宿主上回归。

插件更新无需卸载现有含下载歌曲的 v1.5，保留其原安装包和数据。使用带插件管理器的独立宿主导入 ZIP。

本次覆盖更新：逐字优先查完可用逐字来源后，若均无逐字，按 Apple Music 原生 → AM++ 适配库 → QQ／网易云等第三方的质量顺序选择逐行；手动选源仍优先。译文保留原生／AM++ 当前歌词自带的可靠译文，再补 QQ／网易云，最后机翻。双击来源仅寻找当前来源其他匹配，单击换来源、长按打开设置。

## 1.0.3 / 105 嵌入版验证

105 嵌入版内含 AM++ 1.6.3、Apple Music 7.0.0-beta / 1606。导入 1.0.3 覆盖同 ID 插件后，重启宿主；配置沿用。原有 v1.5 四个安装包无需更新。已有离线伴随 APK 可继续使用，词典注音无需伴随 APK 或 API 密钥。

保留 1.0.2 的发音在上、原文在中、译文在下；全部属于原生歌词行，辅助文字不进入逐字区域。1.0.3 覆盖原生菜单的一/三/四参数入口，捕获首次点击对应的页面。菜单开关与初始化适配器用当前 TTML 实际可显示的轨道判断，用户明确隐藏仍保留；点击显隐调用 Apple 原菜单使用的公开行为入口以保存选择，不直接读取或修改宿主偏好文件。原生解析丢失的逐行译文/发音从原始 TTML 按原文补齐，清除空的延迟文本结果，避免旧句或缓存覆盖。

后续回归可检查 Zutto Futaride、Koigokoro、さよならメモリーズ：冷启动第一次打开菜单、逐字/逐行译文、原生发音开关、隐藏后切歌/重启、突出内容。词典注音、来源和翻译优先级不变。用户已完成105嵌入版实机验收；此列表是回归建议，不表示用户逐项报告过这些场景。

## 下载校验

在附件所在目录打开 PowerShell：

```powershell
Get-FileHash .\Tcrrry-Lyrics-Plugin-1.0.3.zip -Algorithm SHA256
```

主插件应为 `de664c3d3ed40bb626ca006adbba8cce102f519e8b2a83856f86ca731c52d74d`。其他 ZIP、APK 和 `validation.json` 与 `SHA256SUMS.txt` 逐项比较。源码包和二进制中的旧测试说明为归档内容，当前状态见[正式发布说明](RELEASE-1.0.3.md)。
