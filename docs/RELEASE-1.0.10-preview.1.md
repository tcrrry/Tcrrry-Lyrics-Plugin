# 1.0.10-preview.1

先修独立歌词插件的辅助内容准备与刷新。主项目和正式发布不变，离线翻译扩展继续使用1.0.0。

- 原生译文始终优先，可靠的平台译文其次，机翻只补缺失句子。平台结果和本地工作使用独立有界队列，网络查找不能阻塞本地机翻；后到的平台译文可以替换临时机翻。
- 已完成的机翻句子节流提交，不再等待整首结束。部分失败保留已有结果，临时失败短暂退避后可重试。
- 修复不打开语言包设置就无法触发离线机翻的冷连接门槛；后台探测共享连接，并限制同时在途的推理请求。
- 修复结果早于来源登记时不刷新，以及首轮返回使用入队前旧快照的问题。原生结果通道、索引与过期请求保护保留。
- 同一原文与发音在歌词刷新时共用一次后台对齐计算，减少重复排队；停用后的旧结果不能写入新会话。
- 切歌后尚未开始的原生补全工作不继续调用网络或翻译，已运行的翻译在下一条结果时检查当前歌曲并退出。
- 保留日语、韩语、粤语排版、原字号、原生分行、发音／原文／译文顺序及仅原文高亮。

本次只交付主歌词ZIP到桌面，不连接手机、不安装、不发布或替换主项目。测试中的阻塞网络与分阶段完成验证调度和优先级，不代表真实设备推理耗时；首次模型初始化仍可能需要时间。手机效果待自行导入验收。
