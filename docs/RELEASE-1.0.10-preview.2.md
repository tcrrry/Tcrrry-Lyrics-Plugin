# 1.0.10-preview.2

基于 preview.1 的翻译与注音调度修复，继续调整独立歌词插件设置。

- 来源滚动条在内容变化时清除旧循环宽度与帧时钟，并在实际绘制前按当前 TextView Layout 同步几何；避免切换到更长来源描述时两份文字重叠。未变化的轮询不重置滚动。
- 当前歌曲歌词源页：下一来源／下一版本并排，重选最佳／自动选源并排，匹配记录与预览保留独立入口，歌词偏移及重置继续保留。所有设置键、源选择和时间偏移行为不变。
- 主页各入口保持独立：歌词偏好、翻译与注音、歌词效果、更多工具、操作说明；查看当前匹配信息完整保留。
- 不改发音字号、三语言逐字对应、原生换行、发音／原文／译文顺序、仅原文高亮；译文仍原生优先，其次平台，机翻补缺。
- 翻译插件仍为 1.0.0；主项目和已发布版本不变。

使用已配对的独立 ADB 服务端口 5038 验证连接、读取设置层级并传输校验文件。桌面与导入检查不能替代新版在手机实际运行的视觉验收。
