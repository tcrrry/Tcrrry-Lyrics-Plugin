# 1.0.10-preview.6 — 原生跳转过渡与跨行高亮恢复

- 跳转时通过 AM 的歌词 adapter.O 提交退出与重新进入通知，复用宿主原有的 ItemAnimator、行高亮与逐字生命周期；有当前句时移除额外的布局后强制定位，避免打断原生过渡。没有新增插件动画、透明度或位移曲线。
- 间奏无当前句时，布局后通过宿主 ItemAnimatorFinishedListener 等待原生动画结束，再调用宿主原有行定位回调定位下一句。连续跳转时淘汰旧回调，保留单曲循环首句恢复与暂停不启动播放。
- 同一句内跳转也绕过宿主按行 ID 去重：读取原生字词结束时间，向 AM 提交已唱字 ID 快照（含独立的背景人声快照）。跨到同一句的第二个视觉行时，前一行的已唱字不再等待后续逐字事件才补亮；没有给未来字伪造高亮事件。
- 改动只在已确认的歌词页面、歌曲与原生文档上处理进度跳变，正常连续播放不反复提交。注音字号、原文/发音/译文顺序、日语与韩语/粤语注音排版、原生换行及原生译文优先策略保持原样。

验证包括同句跨视觉行跳转、已唱字快照向前/向后恢复、原生动画完成后定位、连续跳转拒绝旧完成回调、暂停跳转不播放及前版循环/间奏回归。自动化检查与原生接口校验不等于真机观感验收；新包交付后需手动导入验证。本次仅修改歌词插件，未改主项目、未发布正式版本。
