# Tcrrry 歌词增强 1.0.10

适用于 AM++ SDK v1，已适配 AM++ 1017 / Apple Music 7.0.0-beta（1606、1609）。本次仅发布歌词插件，主项目暂不更新。

- 设置首页移除顶部插件名称、渠道和版本号，直接展示当前歌曲与设置。
- 修复播放中跳进度时动画缺失、歌词残留及旧回调覆盖。退出与进入分帧执行，等待原生动画生命周期，连续跳转只采纳最新目标。
- 补上小幅跳转、间奏定位、暂停跳转及单曲循环恢复；暂停时调整进度不会自动播放。保留跨行已唱字高亮恢复，不改注音字号与原生分行。
- 修复偶发高亮、聚焦和跟随丢失，保护原生触摸监听，精简新歌词通道下不必要的逐帧工作。
- 优先采用原生译文，其次平台译文，再补机器翻译；离线与网络任务独立执行，减少重复计算和等待。
- 修复切源后来源文字滚动重叠；整理来源操作，点击后保持当前窗口；更多工具与操作说明分别保留。

## 下载与安装

在 AM++ 插件管理器导入 `Tcrrry-Lyrics-Plugin-1.0.10.zip`，覆盖同一插件 ID 保留设置，随后自行完全退出并重新打开宿主。

只有需要离线机器翻译时，另下载并启用 [Tcrrry 离线翻译插件 1.0.0](https://github.com/tcrrry/Tcrrry-Lyrics-Plugin/releases/download/plugin-v1.0.9/Tcrrry-Translation-Plugin-1.0.0.zip)。翻译扩展本次未改动，无需重复更新；不需要安装翻译 APK。其他语言包下载需开启代理，完成后可离线使用。启用融合播放控制时，请停用独立播放控制插件。

## 验证与边界

发布前执行歌词引擎回归、Release Lint、作者 PluginStore 导入与重导入、DEX/SDK 隔离、词典固定哈希、1017 玻璃接口与1609原生契约检查；统计及 SHA-256 见附件 `validation.json` 和 `SHA256SUMS.txt`。

自动化检查不代表所有歌曲与连续操作均已真机验收。少数无正文歌曲持续加载仍是已知问题。本版未处理宿主设置返回的资源异常或其他插件的玻璃接口不匹配。历史版本保持不变，主项目 v1.10 未同步本版修改。
