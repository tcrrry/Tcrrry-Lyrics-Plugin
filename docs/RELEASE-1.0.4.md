# 1.0.4 更新说明

本次修复来自已实机验收的 1.0.4-ruby-r15，正式插件版本为 1.0.4。

- 新增日语字词对应发音，改善原生发音与词典补注的对齐、多行换行、重叠和行距；无法可靠对齐时保留整行发音。
- 修复逐字高亮只走一半、句末突然补亮、多行提前亮起、英文及突出发音中的字母提前亮完。
- 单曲循环使用短距离动画回到第一句，避免整首歌词长距离滚动的卡顿。
- 修复自传歌曲 ID 被资料库异步回写后，歌词长时间加载、匹配成功但不显示或无法同步播放的问题；页面与实时队列核对后才恢复绑定。
- 保存主动隐藏发音的选择，处理原生辅助文字中的转义标记。

在 Tcrrry 歌词设置中开启“字词对应发音”；默认保留整行发音，循环复位默认开启。更新直接导入新 ZIP 后重启 AM++，保留同一插件的配置。

离线翻译伴随 APK 沿用 1.0.3；已安装用户无需更新。完整安装包同步发布为 AMPP-Lyrics v1.6，四种形式均移植上述功能。

验证：r15 已完成 vivo V2359A / AM++ 105 嵌入版真实手机检查；正式版编译、测试、最终 ZIP 导入与校验结果见 validation.json。完整安装包另行构建与验证，不能把插件实测等同于所有安装包均实测。
