# 1.0.5 更新说明

适配 AM++ 1012 嵌入版采用的 Apple Music 7.0.0-beta / 1609，保留 1606 支持。1012 是上游嵌入版发布日期，实际宿主版本码为 1609。

- 新增精确 1609 Hook 档案，调整曲目元数据和当前歌词页面身份的解析。
- 更新歌词列表、发音开关、原生辅助文字、遮罩几何和循环回位的版本映射。
- 在注册 Hook 前核验新映射，未知宿主版本继续拒绝加载。
- 沿用 1.0.4 的逐字时间、字词对应发音、自传歌曲恢复及配置；伴随 APK 仍为 1.0.3，无需重复安装。

导入 Tcrrry-Lyrics-Plugin-1.0.5.zip 覆盖同一插件，然后彻底退出并重启 AM++。无需卸载音乐应用、删除插件或清除歌曲。

验证：1606、1609 均通过 141 项原生歌词扩展接口检查；1609 基础档案通过 257 项检查。另执行编译、单元回归、最终 ZIP 的作者 PluginStore 导入检查和资源校验。1609 尚未手机实测，不能据此宣称逐字动画已在新宿主实机验收。

本次更新独立插件；主页四种 v1.6 完整安装包仍针对 1606，不替换其二进制附件。
