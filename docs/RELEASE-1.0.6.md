# Tcrrry Lyrics Plugin 1.0.6

- 设置页按歌词源、歌词偏好、翻译与注音、歌词效果、更多工具分组。简单选项直接选择，操作说明和匹配信息使用小窗口。
- 播放页入口使用专辑色磨砂玻璃；宿主设置入口沿用宿主底色，子页面保持一致，不透出播放界面。仅小型分段选择控件使用宿主液态玻璃，普通页面使用缓存纹理与原生控件。
- 完善进入、关闭及说明翻页动画，关闭窗口按真实入口边界收回，内容逐渐软化、淡出。隐藏滚动条和页脚分隔线，滚动边缘渐隐。
- 外层歌词源单向滚动，详情完整换行显示，长内容在受限高度内滚动。自动匹配和单曲循环复位保持开启。
- 更多工具新增检查更新与自动提醒开关。首次发现新正式版本主动提醒；支持忽略此版本、稍后一天提醒及关闭自动提醒。关闭自动提醒不影响手动检查，不自动下载或安装。

适配范围仍为 Apple Music 7.0.0-beta / 1606、1609，Android 12+、AM++ SDK v1。本轮设置页 v14 已由用户在 vivo V2359A / AM++ 1012 嵌入版验收；更新检查与提醒策略经过自动测试，未新增手机验收声明。安装包、共存模式及其他设备不因插件验收而视为全面实测。

导入 `Tcrrry-Lyrics-Plugin-1.0.6.zip` 覆盖同一插件，保留配置并重启宿主。独立插件离线机翻仍需单独安装原来的 `Tcrrry-Lyrics-Offline-1.0.3.apk` 并下载语言模型；伴随 APK 字节不变，无须重新安装。平台译文、API 翻译和词典注音不依赖伴随 APK。历史发布与附件保留。
