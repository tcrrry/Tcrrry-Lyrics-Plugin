# Tcrrry Lyrics Plugin 1.0.7

发布日期：2026-10-14。适配 Apple Music 7.0.0-beta / 1606、1609，Android 12+、AM++ SDK v1。

## 更新

- 字词对应发音按可用宽度自然换行，不再为了上下行等长提前拆行；保留原歌词段落、逐字时间和可靠对齐规则。
- 修复默认质量优先、短单元平滑导致已生成歌词缓存反复失效的问题。缓存记录实际歌词设置指纹；影响内容的设置改变时才重新生成。
- 更多工具新增歌词缓存管理：默认 64 MB，可调整 0–1024 MB，按最近使用淘汰旧缓存，支持清理。0 关闭持久保存；不删除导入歌词、配置、词典或语言模型。此额度针对自动生成歌词及匹配记录，不是整个应用的全部缓存。
- 同曲更换歌词、补发音或译文时保留旧内容至新内容准备好；相同正文复用原文档，真正替换时采用短暂淡化、模糊过渡。失败时保留已显示内容。
- 修复共存宿主设置入口玻璃识别；子菜单修改不再重建同曲首页，来源滚动保持连续，不随偏好操作重新起步。
- 保留上版二级菜单、紧凑小窗、磨砂玻璃、入口收回动画、操作说明、完整匹配信息与检查更新。

## 安装

导入 `Tcrrry-Lyrics-Plugin-1.0.7.zip` 覆盖同一插件 ID，保留配置，随后重启宿主。独立插件离线机翻仍使用原来的 `Tcrrry-Lyrics-Offline-1.0.3.apk`；伴随 APK 字节不变，已有安装不用重装。不要同时启用整合包内置插件和另一套重复的歌词增强。

主项目 [AMPP-Lyrics v1.8](https://github.com/tcrrry/AMPP-Lyrics/releases/tag/v1.8) 内置同一套插件代码及 ML Kit，无须伴随 APK。

## 已知问题与验证边界

少数无可用歌词的歌曲可能持续转圈，本版没有修复这一宿主加载状态问题。歌曲 1807802486 的现场、公共接口响应摘要与后续排查范围已保存于 [异常证据](NO-LYRICS-SPINNER-1807802486.md)。本次 QQ 未返回正文，网易云仅返回署名行；不能简单归因于 Apple 服务器或网络，也不能保证强制切源就能取得歌词。

正式构建、测试、最终 ZIP 导入及固定资源校验结果见发布附件 `validation.json`。历史设置预览有用户实机反馈；最新歌词排版、缓存与过渡通过自动检查，不把构建通过写成所有歌曲、设备均已实测。
