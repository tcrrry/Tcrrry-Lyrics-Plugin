# 1.0.8-preview.1 本地预览

歌词偏好新增“隐藏开头署名”，默认关闭。只在 QQ音乐和网易云音乐来源中，隐藏开头连续、带明确角色标签和冒号的作词/作曲/编曲/制作/发行等行。组合角色如“作词/作曲：姓名”也支持。

没有统一可靠的署名标记，识别依赖保守的文本规则。遇到不明确的内容就停止隐藏；单独姓名、公司名、歌曲标题和正文开始后的行不猜测删除。全部只有署名的响应保留原样，避免空歌词文档。

只调整显示，不快进音频，不平移歌词时间，不修改原始歌词缓存。逐字时间保持原样，署名附带的翻译/注音一同隐藏，正文关联键重新连续编号。渲染缓存包含该开关状态，切换后重新生成。

本包尚未融合独立播放控制实验，也未发布正式版本。自动化测试不代表手机验收。
