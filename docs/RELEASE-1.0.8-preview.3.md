# 1.0.8-preview.3 本地预览

## 设置渲染

纯开关统一为“短单元平滑”形式的原生单按钮：开启红色，关闭中性颜色，无独立液态组件和独立玻璃标记。覆盖隐藏署名、日语/韩语/当前歌曲粤语注音、更新提醒、短单元平滑及播放模式优化。

可上下滚动的菜单使用原生分组与原生文字同层绘制，保留磨砂底板和颜色。只有无需上下滚动的紧凑菜单使用实时液态分组。原生按钮材质在布局变化时同步，不在每个滚动帧反复替换背景；滚动页面不再依赖 Compose 浮层逐帧追踪位置。

这是针对渲染路径的减负，自动化测试不能证明手机帧率或真实手势性能，需要实机确认。

## 播放模式优化

“更多工具 → 播放模式优化”默认开启。关闭会卸载该功能的 SDK Hook、退出临时电台单曲循环并重绘原生按钮；开启会重新安装，通过已观察队列恢复状态通知。配置独立保存，不关闭歌词功能。播放扩展仍只适配 1609。

独立播放模式插件仍需停用，融合版通过相同资源声明检测重复接管。

## 署名过滤

补齐 Supervisor、Mastering Producer、混音母带等角色；支持“后期 + 已知角色 + 制作人/工程师”复合标签。匹配歌名的 QQ 头行允许歌手别名。已知署名间的未知制作标签，只有两侧均为明确署名、标签包含制作类角色关键词、且相邻间隔均在三秒内，才作为署名块的一部分隐藏。

快速、冗长文字不是单独删除条件。对话、正文、正文开始后的同形署名、未知来源保留。播放 TTML 和预览继续共用策略，正文时间不平移。渲染缓存策略升级，防止沿用上版漏筛结果。

包含《回音如果》截图所示标签的逐字/逐行回归；测试正文为占位文本，不是原歌歌词。截图原文件留在桌面验证目录。

只交付独立歌词插件预览 ZIP，主项目安装包和正式 Release 未改动。
