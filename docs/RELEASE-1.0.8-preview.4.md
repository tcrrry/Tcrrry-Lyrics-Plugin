这次先用实际网易云歌词复现旧版失败，再修改规则。真实返回中的影视剧说明头行与歌曲短标题不同，导致旧规则提前停止；不只是角色词表缺项。

- 已知角色支持有限组合，例如人声和声、乐器录音、制作企划、歌曲统筹、音乐制作公司、项目统筹、音乐出品；逐段检查，避免把“音乐制作公司”错误剥离成“公司”。
- 补充合声、弦乐团及弦乐录音师/录音棚等录音角色。
- 继续只过滤 QQ/网易云的连续开头署名；快速、密集、冗长不是单独删除条件，正式正文后的文字不删。关闭开关恢复原文。
- 播放和预览共用策略；正文时间不平移。渲染缓存策略升级为第 4 版，原始缓存保留。
