# 1.0.8-preview.8 本地预览

## 手机复现

2026-10-17，无线 ADB 现场确认 Apple Music / AM++ 7.0.0-beta /1609，用户确认运行 preview.7。中文歌《麦穗上的光》正在播放，歌词正常，但原生 `translations_button` 为 GONE，布局 `0,0-0,0`。不是仅透明度变为零。

现场按钮类为 `q.o`。反汇编手机实际宿主后确认，它是 ImageView 的普通子类，没有重写 setVisibility；不能把这个类名本身当作原因。手机安装包内嵌原始 APK 的摘要是 `599972c4296973eff39bb0eb2394c409005da2d2d387a2174c3c1c4ac93cb4e6`，与之前电脑分析输入不同，但已核对相关 F2 和 q8.X4.o0 结构一致。

## 修复路径

preview.7 的提前登记并未解决这台手机的实际问题。此前主要依赖框架 View/ImageView.setVisibility 拦截 GONE；现在对精确 1609 增加原生 `PlayerLyricsViewFragment.F2` 刷新完成后的显式校正，即使原生写入没有经过通用框架拦截，中文歌无翻译/发音时仍恢复方形入口。

从精确映射的原生绑定字段取得真实按钮，不仅依赖 root.findViewById 的生命周期/资源查找。空文档、加载中、连续换歌也走这条完成回调，不依赖辅助轨可用。

保留刷新前的沉浸 INVISIBLE 状态，不把沉浸隐藏误改成显示。不伪造翻译/发音可用状态，不改字体、匹配、缓存、玻璃及播放模式。不新增轮询、逐帧扫描或重复网络请求；F2 回调中不发布/重应用歌词，避免递归刷新。日志只记录前八次按钮状态，不记录歌词内容。

保留 preview.7 的原始标点署名过滤修复和已有功能，1606 不启用此新增精确宿主回调。

## 验证与交付边界

新增测试模拟已登记按钮仍被原生重新写为 GONE，且不手工调用通用框架钩子；还覆盖空文档、沉浸退出、无资源 ID、无关控件及刷新中停止插件。不以电脑测试代替手机验收。

按用户最新要求仅传 ZIP，不导入、不重启、不覆盖手机插件。现场复现已完成，新包实际效果待用户自行导入并重启 Apple Music 后验证。

仅独立插件本地预览，不修改主项目 APK 或正式 GitHub Release。融合播放模式插件使用时仍需停用独立播放模式插件。
