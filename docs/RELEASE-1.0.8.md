# Tcrrry Lyrics Plugin 1.0.8

发布日期：2026-10-17。Android 12+，AM++ SDK v1，Apple Music 7.0.0-beta /1606、1609。

## 更新

- 隐藏开头署名新增开关；从逐条关键词扩展为连续开头区块分析，保护正文、声部、对白及重复演唱内容。修复 QQ 零时长冒号和斜杠被转换器剔除后导致识别失败的问题，播放和版本预览一致，正文逐字时间不变。
- 修复 QQ 个别歌曲逐字轨截断。仅在同一平台记录、正文重合及时间覆盖证据充分时，使用完整逐行轨替换残缺逐字轨，不借用别曲或伪造时间。保留[Anoko 实际样本说明](QQ-INCOMPLETE-1669861760.md)。
- 修复中文歌冷启动时翻译/发音/来源方形入口缺失。1609 原生刷新完成后校正按钮，不伪造辅助轨，不加轮询；保留沉浸模式隐藏。preview.8 经用户确认可用。
- 融合已测试的播放模式插件：从新播放意图进入歌单、专辑、歌手或电台时修复继承的单曲循环；可通过“强制覆盖循环方式”关闭，默认开启。名称调整不改变原逻辑。电台/自动扩展的原生循环按钮适配为既有可选能力，不宣称动态队列等于完整有限歌单。
- 轻量开关开启为红色、关闭为中性，不为每个开关生成实时玻璃；翻译模式、语言搜索、更新提醒和操作说明统一现有设置小窗。
- 主项目新版本通过可选适配器使用同一插件的离线语言包界面：支持中文、English、语言代码搜索，下载状态、下载原语言与中文、删除所选包及错误恢复。独立插件仍由伴随应用管理，旧主项目适配器缺少新接口时保留旧入口。

## 安装

导入 `Tcrrry-Lyrics-Plugin-1.0.8.zip` 覆盖同一插件 ID，保留配置，随后重启宿主。融合播放模式功能时停用独立的播放模式插件。离线伴随 APK 继续使用字节未改的 1.0.3；已安装无需重装。主项目 [AMPP-Lyrics v1.9](https://github.com/tcrrry/AMPP-Lyrics/releases/tag/v1.9) 内嵌同一份代码及 ML Kit，不需要伴随 APK。

## 验证边界

用户已确认 preview.8 方形按钮恢复；播放模式预览亦有用户确认。新语言包小窗通过自动交互、异步状态及紧凑宽度渲染测试，正式插件和四种主项目新二进制不视为全部实机验收。构建、最终 ZIP 导入及摘要见发布附件 validation.json。

署名识别仍是保守启发式，不承诺任意格式零误删/零漏删，可关闭恢复原文。个别无可用歌词持续加载的问题仍未解决，保留[歌曲 1807802486 的证据](NO-LYRICS-SPINNER-1807802486.md)，不简单归因于 Apple 服务器或网络。
