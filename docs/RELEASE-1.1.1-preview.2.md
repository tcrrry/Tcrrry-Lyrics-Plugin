# 1.1.1-preview.2

本次只更新歌词插件，保留 preview.1 的 1017、结果提交和切换源修复；不替换宿主，不发布主项目。

- 日语逐字发音对齐增加 QQ 的 qi/chi、xia/sha、kiyo/kyo 等写法，以及省略促音、长音的空间匹配。读音全文仍须由词典或假名验证；保留来源的实际字母，不修改罗马字、注音字号或逐字时间。
- 支持全角/半角数字的完整日语读法和“ヶ月”等月份计数的促音变化，修复“３６ヶ月”；使用词典支持的前后词读音识别“片っ方”等口语促音复合词。
- 初次查找没有可用歌词时也发出完成通知，在原生加载区域显示“暂无歌词，请欣赏音乐”；标题明确标有 instrumental/伴奏等时显示“纯音乐，请欣赏”。调用 1609 已核对的 o2 取消延迟加载。不会把网络失败推断为纯音乐，不写入虚构歌词或时间，不自动切走歌词页。
- 后续歌词到达、切歌或停用插件时清理提示，保留正常的原生歌词安装和播放操作。

现场：无线 ADB 观察到徐梦圆《China-P》播放超过两分钟时歌词页仍显示 loading_progress。旧代码没有在首次空结果后通知页面停止加载。此次代码、打包验证和独立 Android 进程探针与实际导入后的播放页验收分别记录，不能相互替代。
