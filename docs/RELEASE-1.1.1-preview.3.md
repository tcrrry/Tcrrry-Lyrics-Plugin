# 1.1.1-preview.3

仅更新歌词插件，继承 preview.2；不替换宿主或主项目。

- 将资料库歌曲的身份校正接入 1017 结果提交路径。仅当资料库 ID、队列 ID 和实时播放信息一致时，校正播放页别名，重试已准备好的歌词；不重放播放器元数据，不以歌名猜测身份。
- 读取 Apple Music Windows 属性中同步的“自定歌词”。严格识别完整 LRC 后转换为逐行时间轴，保留时间戳和空白结束行；普通纯文本、混合无时间戳文本和有冲突的同步行不转换。不虚构逐字时间。
- 自定歌词优先于自动网络匹配，显式选择其他来源仍生效；插件手动 TTML 映射仍优先。转换结果沿用离线注音、翻译和繁简显示流程。
- 实际歌词加载项晚于元数据提供自定文本时，触发一次重新准备。停用时清理缓存。

验证需区分单元测试、真实 ZIP 导入检查与手机验收。手机需手动覆盖导入本预览包后，以自导入的《桃花诺 (Live版)》复测时间戳隐藏、逐行跟随和来源状态；这一步尚未完成。
