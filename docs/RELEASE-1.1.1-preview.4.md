# 1.1.1-preview.4

仅更新歌词插件，继承 preview.2 的功能和 preview.3 的资料库歌曲身份校正。不修改宿主或主项目。

- 撤回 preview.3 对 Apple Music Windows“自定歌词”的 LRC 转换，不将用户随意导入的文本当作优质 AM 原生时间轴。
- 检测到自定歌词时，自动选择不授予 AM 原生优先权，也不以自定歌词覆盖 QQ、网易云等来源的逐行结果。保留正常来源匹配和择优规则。
- 显式选择 AM 来源时保留其原样显示；插件自己的手动 TTML 映射不受影响。真正的 AM 原生歌词沿用原有优先规则。
- 保留资料库 ID、队列 ID 与实时播放身份一致时的别名校正，避免结果已经准备好却无法提交到自导入歌曲页面。

需手动覆盖导入后，以带 Windows 自定歌词的资料库歌曲验证自动匹配、手动选源和实际页面跟随。桌面测试与 ZIP 导入检查不代表手机页面已验收。
