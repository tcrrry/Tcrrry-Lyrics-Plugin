# 1.2.1-preview.2 — Apple Music 1614

- 增加 AM++ 1.6.8 嵌入版对应的 Apple Music 7.0.0（1614）适配；保留 1606、1609 和 1613。
- 逐项检查原始宿主的歌词与播放队列接口；为 1614 歌词适配器的方法重排增加独立映射，保留旧宿主映射。
- 包含 preview.1 的突出发音菜单状态、多演唱者发音处理和原生歌词译文对齐修复。
- AM++ 宿主自动补全与插件的 AM++ 作者整理库仍是各自独立的歌词来源；本版未重新设计来源追踪。
- 这是预览版：自动接口检查、构建与导入检查不能代替手机播放实测。需在 1614 上测试逐字/逐行歌词、注音、翻译、切歌拖动、辉光、菜单与播放模式，并回归旧宿主。
- 离线翻译仍使用原有的独立翻译插件；如同时安装独立播放模式插件，请避免重复启用合并的播放模式功能。
