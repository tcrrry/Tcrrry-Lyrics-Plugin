# 1.2.1-preview.3

继承 preview.2 的 1614 适配与之前的歌词预览修复。

- 强制覆盖循环方式改为识别原生歌手页播放按钮及歌单、专辑等页面的播放／随机播放按钮，再关联后续队列提交；单独点歌曲行不会仅因替换队列而触发插件清除单曲循环。
- 后来的点击会取消尚未提交的旧按钮意图；按钮意图单次使用且短时失效。手动变更循环方式、远程队列和队列提交失败仍沿用原保护逻辑。
- 此版本尚未在 1614 手机上验证。请测试歌手页播放按钮、歌单播放和随机按钮，以及歌单／搜索结果／歌手页点单曲后的循环模式。不同页面的原生布局或异步队列行为仍可能影响识别。
- 播放模式优化与独立播放模式插件不要同时启用；离线翻译仍使用独立插件。
