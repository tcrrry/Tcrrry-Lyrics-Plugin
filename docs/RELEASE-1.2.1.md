# Tcrrry 歌词增强 1.2.1

- 适配 AM++ 1.6.8 嵌入版／Apple Music 7.0.0（1614），保留 1606、1609、1613 支持。
- 强制覆盖循环方式仅在识别到页面播放或随机按钮后处理队列；点击单曲不再仅因替换队列而清除单曲循环。后续用户操作使旧意图失效。
- 合入多演唱者歌词的发音突出可用状态、菜单刷新以及原生逐字／逐行译文对齐修复。
- 可选离线翻译仍由独立翻译插件提供；启用合并播放模式时请停用独立播放模式插件。

1614 原包接口与 SDK、自动测试、构建和插件导入已检查。不同设备与页面的按钮识别、歌词及动画仍需实机回归。宿主补词来源识别与纯音乐禁用第三方歌词功能本版未重新设计。
