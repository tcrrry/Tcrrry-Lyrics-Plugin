# Tcrrry 歌词增强 1.2

适配 AM++ 1024（1.6.7）与 Apple Music 7.0.0-beta / 1613，继续支持 1606、1609。本次只发布歌词插件，主项目与可选翻译插件保持现有版本。

- 新增 1613 的歌词结果提交、注音排版、原生跟随、辉光和设置页面适配。修复 1024 液态玻璃选项条接口变化带来的兼容问题。
- 可选播放模式优化支持 1613，原生循环按钮按资源名定位，保留原有设置。
- 合入此前预览版的日语数字和口语读音对齐，以及无歌词时停止加载并显示提示的处理。
- 修复自导入歌曲在资料库 ID 与播放页 ID 不一致时，歌词准备完成却未提交的问题。
- Windows“自定歌词”不再转换为优先的原生歌词；自动选择正常匹配 QQ、网易云等来源，真正的 AM 原生歌词仍保留原有优先规则。
- 保留发音在原文上方、译文在下方、注音字号、仅原文逐字高亮和来源切换设置。

在 AM++ 插件管理器覆盖导入 `Tcrrry-Lyrics-Plugin-1.2.zip`，按管理器提示重新启动宿主。需要离线机器翻译时继续使用 `Tcrrry-Translation-Plugin-1.0.0.zip`；无需安装翻译 APK。使用合入的播放模式优化时停用独立播放模式插件。

验证依据见 [1024 适配记录](ADAPTATION-1024.md)。已对照实际嵌入包检查接口；实机播放与动画效果尚待验证，请保留旧版本以便回退。
