# Tcrrry 歌词增强 1.3

适配 AM++ 1.6.9／Apple Music 7.0.1（1622），保留 Apple Music 1606、1609、1613、1614 支持。

- 开启「强制覆盖循环方式」后，专辑顶部「播放」和「随机播放」在新队列生效时退出单曲循环。随机按钮继续使用 AM 的随机排序。直接点歌曲仍保留单曲循环。
- 修复「自动匹配来源顺序」打开时的闪退，支持拖动排序，并按质量优先或逐字优先的规则应用顺序。
- 恢复 1622 的逐字发音排版，改善译文、发音的可用状态。可通过「重新装载译文和发音」重试当前歌曲。已缓存歌词更少重复联网。

在 AM++ 插件管理器导入歌词 ZIP 即可覆盖旧版。现有宿主 APKS 可继续使用。离线机翻扩展仍使用 1.0.0。

已在 1622 真机日志中核对预览版的专辑顶部播放和随机两条路径，两次换队列后都清除了单曲循环。正式包另做构建、单测、接口和导入检查。
