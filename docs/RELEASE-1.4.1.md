# Tcrrry 歌词增强 1.4.1

适配 AM++ 1.7.1／Apple Music 7.0.3（1626），并保留旧版宿主支持。

### 智能混音流畅度与动画修复
- 修复智能混音末尾阶段音量回调竞争、`crossingTimeUs` 误写及异步写盘/UI 重试引起的卡顿，重构 `doFadeIn`/`doFadeOut` 单一等功率淡化曲线并在开启「保留 Apple 曲线」时保留原生切点。
- 智能混音自动时长范围扩展至 **0~10 秒**：面对匹配度极低或人声持续到结尾的曲目，自动缩短为 1~3 秒甚至 0 秒自动跳过，不再强行叠音。
- 修复旧偏移 `secondTrackOffsetUs` 导致的歌曲中段误触假过渡，并在切歌、拖动进度条及状态复位时即时回收进度条曙光与「智能混音」标签动画，新增硬超时看门狗防止动画长期残留。

### 移除「有线耳机优化」
- 因多数未 Root 的 Android 机型系统 HAL 未开放 `BIT_PERFECT` 源码直通，强行请求 `MIXER_DEFAULT` 反而易引发时钟失配与持续卡顿，本版移除该实验性功能。
- 从 1.4 升级到 1.4.1 时会自动清除旧有混音器偏好，恢复系统原生稳定输出通道。

在 AM++ 插件管理里导入 **Tcrrry-Lyrics-Plugin-1.4.1.zip**，可覆盖旧版歌词插件并保留设置。
