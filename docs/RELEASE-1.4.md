# Tcrrry 歌词增强 1.4

适配 AM++ 1.7.1／Apple Music 7.0.3（1626），并保留旧版宿主支持。

### 歌词与注音增强
- 新增「插件歌词源修改」全局总开关，关闭后完全回退 Apple 原生歌词与控制面板。
- 自动过滤纯英文歌与多语种混排歌曲（如粤英混排）英文行的冗余英文发音，同时完整保留粤/日/韩/俄语注音。
- 修复单曲循环及跨曲过渡后 `MediaBrowser` 时钟滞后导致的歌词反复上下重定位问题。
- 优化已缓存歌词的首屏加载（修复磁盘缓存与原生歌词竞态并放宽缓存优先等待窗口，未命中时即时回放原生），减少复播闪烁。

### 智能混音（自动过渡）
- 将「智能混音（自动过渡）」提升至「更多工具」一级入口并与 Kifranei 开关解耦；若同时安装独立版 K 插件且对方开启了自动过渡，仍自动让位不冲突。
- 优先采用 Apple 官方 `AudioAnalysis` 数据并与本地分析结果分池缓存，切换开关零卡顿。
- 重构 GPU AGSL 曙光进度条光效（跟随专辑色调融合暖白微光，严格对齐轨道两端并随控制栏同步隐藏），加入切歌平滑滑回、主封面分区溶解及歌词页迷你封面／标题柔和过渡。

### 更多工具融合
- **长按倍速播放**：播放页长按下一首快进（1.25x~3.0x）、长按上一首慢放（0.50x~0.90x），基于原生 `AudioTrack.setPlaybackParams` 输出无杂音，支持松手恢复／锁定模式与保留音调选项。
- **有线耳机优化**、**强化睡眠定时**、**自定义歌单封面修复**、**播放列表多选导出**（TXT/CSV），以及按能力共存避让的 **Kifranei 媒体外观增强**。
- 在「更多工具 → 诊断日志」新增常驻轻量滚动日志（歌词／智能混音／有线耳机），支持一键导出至下载目录或复制反馈。

在 AM++ 插件管理里导入 **Tcrrry-Lyrics-Plugin-1.4.zip**，可覆盖旧版歌词插件并保留设置。
