# 可选离线翻译扩展 1.0.0

与歌词插件 1.0.9 配合使用。两个文件都是 SDK v1 插件 ZIP，在 AM++ 插件管理器中导入；不用安装 APK。

- 只需要歌词功能：只导入歌词插件 ZIP。原有平台译文、API 翻译、词典注音、繁简转换及播放控制保留。
- 需要离线机翻：再导入并启用 `Tcrrry-Translation-Plugin-1.0.0.zip`，自行完全退出并重新打开宿主。
- 中文模型为内置必需资源，首次使用从扩展内解压，无需联网下载，不提供删除。
- 英语无需额外下载。其他语言按需下载；下载语言包需要开启代理，并允许本应用及系统下载服务通过代理访问 Google。
- “离线翻译”面板直接提供搜索栏，输入后显示匹配语言，标记已下载语言，并显示下载进度/状态；下方提供“已下载语言包”和“检测离线翻译”。管理面板可确认后删除额外模型。
- 模型存储归翻译扩展所有；旧合并试验包的模型数据保留在歌词插件原目录，不会被更新删除，新扩展不会擅自读取其他插件私有数据。

模型下载有实际字节信息时显示百分比，连接、等待网络、校验和失败状态单独显示。不伪造进度。
关闭窗口不再刷新已关闭的界面；已交给 Android 下载管理器的任务可以继续。停用扩展会断开请求，歌词其他功能继续工作。

原生库和 ML Kit 工作线程可能保留至宿主进程退出，因此更新后需自行重开宿主。没有修改或重新打包宿主。

内置模型来源：Google ML Kit translate 17.0.3 的 v5/high/r29/en_zh.zip。
模型 SHA-256 与 SDK 自带元数据一致：`ab077c810b001d16667877d9fcda565a206718128a5163428ab5b6ace08936c4`。
手机临时进程已从内置模型得到真实译文“Hello, world → 你好，世界”，没有在线下载模型或调用伴随 APK。
键盘窗口标志、搜索、状态进度、删除保护和两插件协议另有自动回归测试；宿主内的新界面和其他语言下载仍需实际使用验收。
