# 1.0.4 验证范围

正式版代码来自已验收的 r15，版本名称、正式文档与设置中的试验标签已整理。

真实手机：vivo V2359A，AM++ 105 嵌入版，Apple Music 7.0.0-beta / 1606。已检查自传歌曲资料库 ID 恢复、歌词加载与进度同步、日语单/双行发音、英文多行高亮、前后拖动与单曲循环短距离回首句。用户已确认自传歌曲修复生效。

自动验证：正式源码编译、engine/offline 单元测试、作者 PluginStore 对最终 ZIP 的导入/重导入/配置保留检查、ZIP/DEX/资源校验。具体测试数量与哈希以发布附件 validation.json 和 SHA256SUMS.txt 为准。

边界：这是抽样实机验证，并非每首歌、每个宿主版本和每种设备全面验收。录屏不含音轨，逐字视觉推进检查不等同于音素级音频同步测量。共存宿主及完整安装包的验证单独记录。无法可靠对齐的发音保留整行。
