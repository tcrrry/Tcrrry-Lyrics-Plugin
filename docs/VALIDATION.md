# 插件 1.0.2 验证范围

1.0.2 以 v1.5 正式版和独立插件 1.0.1 为基线，只修改独立插件。移除 overlay 加顶部留白的布局：发音在上、主歌词在中、译文在下，均属于原生歌词行，但辅助轨道不属于 FullWidthAlphaGradientFlexboxLayout 的逐字子视图或遮罩。实际主轨道的原生逐字映射保持不动。

已解包原作者的 105 嵌入版：AM++ 1.6.3 / 113、Apple Music 7.0.0-beta / 1606。核对实际宿主 DEX、SDK 方法签名及新增的原生 karaoke 行绑定字段、辅助文本 getter；代码只适配这组已核对名称。

新增回归使用真实 AndroidX ConstraintLayout 与 Flexbox 测量，验证窄屏、多行发音及译文互不重叠，顶部 padding 不变，主词索引不变，辅助文字不进入逐字绘制。模拟 1606 形状的宿主适配器通过真正的 SDK Hook bridge 测试：整行绑定中同时关闭原生辅助渲染，绑定完成后补齐；即使缓存命中且没有调用内部逐字重建，也能恢复发音；显隐 payload、普通刷新和行复用保留正确状态、恢复原生标志。模拟宿主类和 AAR 测试资源只在测试目录，不会编入插件。

原始 TTML 的注音/翻译兜底按原文准确匹配，不使用容易受空白行影响的 lineId 当数组序号；相同原文对应不同注音时拒绝猜测。继续保留 1.0.1 的同步词典注音、网络失败保留发音、平台译文优先级与生命周期回归。

完整回归、Lint、作者未修改 PluginStore 的真实 DEX ZIP 导入、重导入配置保留，以及最终签名和 SHA-256 见下载页 validation.json / SHA256SUMS.txt。

云端无法运行手机上的 105 宿主实际播放。仍需复测 Zutto Futaride、ロマンスの約束、My Way、Spring Thief、Marigold，以及突出歌词/发音、连续切歌、显隐切换与字体缩放。桌面测量和模拟绑定通过，不代表已确认所有设备动画和宿主插件共存都正常。本版保留测试标记，等待实机反馈。

既有 v1.5 四个安装包、签名和下载内容不动。词典发音无需密钥或离线翻译伴随 APK；已安装的 1.0.0 / 1.0.1 伴随 APK 可以继续使用。
