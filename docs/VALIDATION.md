# 插件 1.0.3 验证范围

## 正式发布验收（2026-10-08）

用户已在 **AM++ 105 嵌入版**完成 1.0.3 实机测试，反馈暂未发现问题并授权正式发布。没有新增用户逐场景测试记录，也不宣称所有后续 AM++ 版本兼容。本次仅迁移仓库和更新发布文档，复用已验收的全部五个附件，不重新构建。

以下内容是此前云端工程的验证记录：`validation.json` 统计 engine 466 项通过、1 项跳过，offline 5 项通过，共 **471 项通过**；Lint 0 错误，engine 57 条、offline 9 条警告；255 项宿主符号核对、10 个 SDK 类/42 个公开方法签名核对无失败。最终 ZIP 导入、重导入及配置保留检查通过。云端没有执行真实手机播放测试。

正式 Release 原样保留 `validation.json`。其中 `deviceTests: not-run; user retest in 105 embedded host required` 描述的是云端验证时点，后续用户验收记录见本节和[正式发布说明](RELEASE-1.0.3.md)。源码包及插件内旧文档同样按原字节保留，以保持全部附件及校验文件一致。

## 原始云端验证范围

本次只修改独立插件，保留 1.0.2 已验证的原生同行布局与逐字遮罩隔离，v1.5 四个安装包不变。

实际105宿主为 AM++ 1.6.3 / 113、Apple Music 7.0.0-beta / 1606。继续核对255项适配描述和SDK签名，另核对首次菜单点击页字段、F2/t2/u2、PlayerLyricsViewModel辅助轨道LiveData getter、逐行处理器及原菜单显隐设置入口。原生菜单直接调用三参数弹出方法，因此一/三/四参数均拦截，且无先前anchor注册也能添加两行插件菜单。

可用性以当前TTML实际非空辅助内容与原生已识别轨道为依据。辅助显示开关不再依赖原生语言过滤；t2/u2覆盖初始化适配器选择，F2结束后补齐可用性并重放现有选择。重放只发出原生状态通知，不保存新选择或重新开启用户主动隐藏的轨道；用户点击使用Apple原菜单相同的选择行为入口。插件不直接读取/修改宿主偏好文件。只有被观察到且有辅助文字的原生文档被登记，没有正文/可用轨道不凭空启用按钮。

新增回归涵盖：冷启动首次菜单无anchor、三个弹出入口及嵌套重复、菜单替换后固有宽度非零、原生已有轨道保留、空白轨道仍灰、用户隐藏保留、初始化适配器选择、可用性重放与实际显隐保存入口、移除插件菜单后恢复原有行。逐行回归包括整行绑定、旧句缓存、原生空延迟文本、原生优先、显隐和空行/重复原文抑制。继续运行1.0.2的真实ConstraintLayout/Flexbox测量、逐字缓存、译文隔离与全部匹配/翻译/生命周期回归。

最终DEX验证排除SDK、作者模块和测试宿主类，词典素材校验保持一致；作者未修改的PluginStore验收最终ZIP导入、重导入和配置保留。统计、Lint、ABI与签名见validation.json，发布附件校验见SHA256SUMS.txt。

云端未运行手机105宿主播放。此前建议复测 Zutto Futaride、Koigokoro、さよならメモリーズ，以及冷启动菜单、源切换、突出内容、显隐后重启和字体缩放。桌面/模拟绑定通过不能代替实机验收。后续用户已完成105嵌入版验收，1.0.3现为正式版；旧私人仓库的测试版发布历史保留，已有离线翻译伴随APK可继续使用。
