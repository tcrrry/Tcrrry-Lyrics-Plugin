# 插件 1.0.1 验证范围

1.0.1 以既有 v1.5 正式版及插件 1.0.0 为基线，只修改独立插件。发音改为原生逐字容器内的独立绘制层，普通刷新保留逐字缓存和发音，离线注音在歌词读取工作线程先补齐，平台译文和机翻异步执行。

已解包原作者的 105 嵌入版，实际为 AM++ 1.6.3 / 113、Apple Music 7.0.0-beta / 1606。实际宿主 DEX 的 255 项适配描述检查通过，嵌入模块内 10 个 SDK API 类的 42 个公开方法签名与编译 SDK 相符。

回归包括：首份原生逐字歌词无需等待网络即可带词典发音；网络失败仍保留发音；已有平台发音不被覆盖；顶部发音不占原生逐字子视图索引；Android 绘制发音在逐字渐变之后；换行、重复布局与回收不累加顶部留白；普通刷新不重建逐字映射，歌曲和显隐改变时才重建。

完整回归、Lint、真实插件 ZIP 通过作者未修改的 PluginStore 导入、重导入保留配置，以及最终 SHA-256 见下载页 validation.json 和 SHA256SUMS.txt。测试目录内的作者 PluginStore/PluginPackages 不打包到插件。

云端测试没有运行手机上的 105 宿主播放，仍需复测截图中的 My Way、Spring Thief、Marigold、P.S. 等身大的ラブソング，以及发音开关、突出发音/歌词、连续切歌、字体缩放。导入及桌面绘制测试通过不等于已经验证了实机 Hook 共存及所有歌曲。

既有 v1.5 四个安装包、签名和下载内容保持不动。词典发音无需密钥或离线翻译伴随 APK；已安装的 1.0.0 伴随 APK 可以继续使用。
